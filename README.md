# Imagen Studio

Direct the image, choose the draft, and refine the actual file.

One portable entry covers Fast, Guided, Studio, and local ASCII work. It preserves the original production workflow, policy, artifact manifest, and native MCP adapter as separate execution surfaces.

```sh
python3 scripts/capability.py doctor
python3 scripts/capability.py install --dest ~/.agents/skills
```

No service starts, image uploads, or generation occurs during method installation. [Native release guide](docs/NATIVE-README.md), [installation](docs/INSTALL.md), [migration](docs/MIGRATION.md), and [actual checks](docs/VALIDATION.md) distinguish method, local development adapter, and prior release results. Optional ASCII conversion needs Pillow; provider execution needs an independently installed compatible MCP server.

Build the local family site with `python3 scripts/capability.py build`, then `python3 scripts/capability.py check`. Its example is explicitly fictional. Nothing is remotely renamed, deployed, or published.
